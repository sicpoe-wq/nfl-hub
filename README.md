# NFL Gridiron

Android app (Kotlin / Jetpack Compose) for NFL rosters, stats, injuries, schedules, scores, standings, leaders and news, using ESPN's public data. Opens to the Philadelphia Eagles by default; all 32 teams available.

Download the latest APK from [Releases](https://github.com/sicpoe-wq/nfl-hub/releases/latest).

Package id: `com.tim.nflhub` (unchanged from the earlier "NFL Hub" builds, so new versions install as updates).
